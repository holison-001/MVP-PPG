# PPG UART 연결 보드 v0.1

기존 PPG와 전선 6개로 연결하는 전이중 RS-422 ↔ 3.3V UART 변환 보드다. 같은 작업 폴더에 별도 KiCad 프로젝트로 작성했다. 외부 9V를 PPG와 공유하고, 사용자 지정 LD1117-3.3V로 이 보드의 통신부와 UART 포트용 3.3V를 만든다. MCU는 추가하지 않는다.

회로도와 PCB 배치·배선을 완료했다. 외곽 고정홀 4개와 홀 주변 Ø11mm 조립 여유를 반영했다. 현재 연결 보드는 52×25mm 직사각형, 6층·0.8mm 기준이다. 모든 SMT 부품과 전선 납땜 패드는 B.Cu에 배치했다. KiCad 기본 위에서 본 좌표 기준 PPG 6핀은 하단 왼쪽 외곽, UART 4핀은 하단 오른쪽 외곽, 9V 입력은 상단 외곽이다. 연결 보드는 기존 PPG와 별도 프로젝트로 관리하며 제조 패널·거버는 아직 생성하지 않았다.

## 연결

| 단자 | 핀 | 신호 / 방향 |
| --- | --- | --- |
| J1 전원 | 1 / 2 | 외부 9V 입력 / GND |
| J2 PPG | 1 / 2 | PPG 공급 9V / GND |
| J2 PPG | 3 / 4 | PPG TXP / TXN → 연결 보드 수신기 U3 A / B |
| J2 PPG | 5 / 6 | 연결 보드 송신기 U2 Y / Z → PPG RXP / RXN |
| J3 UART | 1 | 3.3V 전원 출력 |
| J3 UART | 2 | TX_OUT: 연결 보드 출력 → 외부 장치 RX |
| J3 UART | 3 | RX_IN: 외부 장치 TX → 연결 보드 입력 |
| J3 UART | 4 | GND |

J2의 1~6번은 기존 PPG J1~J6에 각각 연결한다. PPG의 `12V_IN`/`12V`는 기존 네트 이름으로, 실제 공칭 공급은 9V다. 이 보드 J3.1은 입력이 아닌 LDO 전원 출력이다. 세 연결부는 우선 도금 구리 납땜 패드(지름1.2mm·피치1.8mm·솔더 페이스트 없음) 풋프린트로 지정했다.

## 적용 부품과 출력 안정화

회로도 Value는 `22 Ω`, `10 kΩ`, `100 nF`, `22 µF`처럼 숫자와 단위 사이를 띄워 통일했다. 전압·허용오차·유전체는 숨김 Voltage/Tolerance/Dielectric 필드와 BOM 열에 보존한다. 미지정 정격은 추정하여 채우지 않는다. IC·TVS·비드는 기존 MPN의 전체 품번을 표시한다.

- U1: **ST LD1117S33TR / SOT-223**, 핀1 GND, 핀2·탭 3V3, 핀3 9V_LDO.
- R1~R8과 모든 MLCC는 **미터1608(1.6×0.8mm, 인치0603)**. **R9는 미터3216(3.2×1.6mm, 인치1206)**. 탄탈은 사용하지 않는다.
- C1: 10µF/25V 입력 벌크. C3: 100nF/25V 입력 바이패스. C4/C5: 100nF/25V 통신 IC 바이패스.
- C2/C6/C7/C8: TDK **C1608X5R1A226M080AC**, 각각22µF/10V/X5R/±20%, 병렬4개. 공칭 합계88µF.
- R9: 1Ω / 미터3216(1206). 연결은 `3V3 → R9 → COUT_BULK → 병렬 MLCC4개 → GND`다. **R9는 부하 전원선에 들어가지 않는다.**
- U2 XR33194ESBTR 송신기 DE=3V3, U3 XR33183ESBTR 수신기 /EN=GND로 상시 활성화한다. R6 10kΩ은 호스트 입력 미구동 시 DI를 UART 유휴 HIGH로 유지한다.
- 수신 종단 R1 120Ω은 PPG TXP/TXN 도착부에만 둔다. 반대 방향 종단은 PPG에 있는 R3 120Ω을 사용한다. 차동선에는22Ω, UART 측에는100Ω 직렬저항을 둔다.
- 차동선에 Bourns CDSOT23-SM712 두 개, UART TX/RX에 TI ESD351DPYR 두 개를 적용했다. PCB에서는 외부 패드→TVS 접점→직렬저항→IC 순서와 짧은 GND 귀환을 구현한다. 9V 입력 TVS는 이 초안에 임의 선정하지 않았다.

LD1117 고정형의 출력 커패시터 최소값은10µF이다. ST 기술 답변은 MLCC 사용 시0.5~10Ω 직렬저항을 안내하므로 이 설계에서는1Ω을 적용했다. 22µF MLCC의 공칭값을 실효 용량으로 취급하지 않았다. 보관한 TDK 제조사 특성 문서의 DC 바이어스 그래프에서3.3V 부근은 부품당 약7~8µF로 읽히므로4개 합계는 약28~32µF인 **참고치**다. 이는 제조사 보증 최솟값이나 실물 안정성 시험 결과가 아니다.

## 검증

KiCad10.0.5 ERC 오류0·경고0. 실제 넷리스트의28개 부품·73개 핀을 기대 연결과 대조했고, 모든 풋프린트를 실제 로드하여 핀 번호를 확인했다. LD1117 탭=핀2, UART 방향, 종단 위치, R9의 커패시터 분기 연결, R1~R8 및 모든 MLCC의1608 규격, R9의3216 규격을 확인했다. SVG와 PNG를 렌더링하여 한글·기호·텍스트가 용지와 도면 표제란 안에서 겹치지 않는지 검토했다. 검증 범위는 회로도 연결과 부품 매핑이며 PCB DRC나 실물 ESD/부하 시험을 수행했다는 의미는 아니다.

표기 통일 후 native 넷리스트를 다시 내보내 73핀·17넷이 변경 전과 동일함을 확인했다. 심벌·핀·배선의 UUID와 배치 좌표도 동일하다. 현재 회로도·BOM·manifest 값/정격이 일치하고, 생성기를 파일 출력 전까지 메모리에서 평가한 결과도 현재 회로도와 일치한다. 저항9개를 포함한 모든28부품의 실제 풋프린트를 로드해 패드 번호를 확인했다.


## PCB 배선 검증 — 2026-10-09

- 28개 부품, 74개 실제 패드(회로도 73핀; U1의 OUT 리드와 탭이 모두 핀2).
- L1·L2·L3·L5는 배선 없는 GND 면. L4는 3V3 분배와 GND, L6는 부품 사이 짧은 배선과 GND.
- 전층 GND 6개 영역 모두 공통 GND에 연결. L1~L5 외곽 GND는 연속된 폐루프이며, 외곽에서0.36~0.55mm 안쪽 띠는 완전히 GND로 덮인다.
- 최소 실제 신호 배선0.20mm, 설정 최솟값0.15mm. 비아61개: GND56개(외곽/내부 추가 스티칭37개), 전원5개. 비아 규격은 아래 최신 드릴 변경 절을 적용한다.
- J2의 차동4선과 J3의 UART2선은 TVS 신호패드 접점을 통과한 뒤 내부로 이어진다. TVS 전단 비아 없음. TVS 패드 영역의 동박을 제거하면 각 외부→내부 경로가 차단되는 것을 기하 검사로 확인했다.
- DRC 오류0·경고0, 미연결0, 회로도 불일치0. 부품 courtyard·몸체·패드 간섭0, 비아와 SMT패드의 동박/드릴 겹침0.
- 중복 분기 배선을 제거하고 FB1→LDO 입력을 직선으로 연결했다. R9는1Ω/3216이며 출력 커패시터 전용 분기에 유지했다.

검증은 KiCad 규칙, 회로도 일치와 저장된 PCB 기하 검사 범위다. 기구 외형 확정·제조 패널·거버·실물 시험은 이번 작업에 포함하지 않았다.

## 외곽 연결부 재배치 — 2026-10-09 (현재 상태)

- 보드52×25mm와 Ø3 NPTH 4개/Ø11 조립 여유는 유지하고, 실제 전선 패드를 현재 보드 외곽으로 이동했다. 모든 부품과 패드는 B.Cu다.
- J1 9V 입력: 상단, pin1(102.5,99.75)mm. J2 PPG6: 하단, pin1(101.5,122.25)mm. J3 UART4: 하단, pin1(121.1,122.25)mm. 각 포트는0°이며 번호가 왼쪽부터 증가한다(위에서 본 좌표). 바닥면 미리보기는 실물 부품면 방향으로 반전하므로 좌우가 바뀐다.
- 패드 동박 끝과 외곽 사이0.65mm를 남겼으며, 각 패드에서 보드 밖으로 직선으로 전선을 뺄 수 있다. 인출 경로에 다른 부품·고정홀 조립 영역이 없다.
- PPG 입력은 외곽 패드→D1/D2 TVS 접점→종단/직렬저항→U3/U2 순으로 수직 배선했다. UART는 외곽 패드→D3/D4→R7/R8 순서이며, 작은 TVS는 GND패드가 신호 직진 경로에 놓이지 않도록 옆으로 배치했다.
- L3에 UART 내부신호2개, L4에3V3/공유9V를 배선했다. L2는 무배선 GND, 전층 GND 연결 및 L1~L5 외곽 연속성을 유지했다.
- LDO·비드·입출력 벌크부품 및 고정홀13개 위치/값/네트와 지정 LDO 동박을 보존했다. 이동한 통신 IC의 바이패스 MLCC도 전원핀 근처에 다시 배치했다.
- 배선86개·비아100개. DRC 오류0·경고0, 미연결0, 회로도 불일치0. 모든 비아100개와 SMT패드74개의 동박/드릴 겹침0건(동일넷 포함). 전층 GND6/6 연결 및 ESD6경로 검사 통과.
- 전기적 회로와 핀 배정은 변경하지 않았다. `edge_port_layout.json`과 `placement_and_routing.json`에 최종 배치·출선 방향을 기록했다.
- 수정 전 전체 백업: `../../backups/adapter_before_edge_ports_20261009_184715/ppg_uart_adapter/`.

## 비아 드릴 기본 규격 변경 — 2026-10-09

- 기본 비아 규격은 **외경 Ø0.50mm / 드릴 Ø0.25mm**다. 신호·GND·전원에 동일하게 적용한다. 현재 비아100개 중 기존 Ø0.20mm 드릴93개를 Ø0.25mm로 변경하고 기존 Ø0.25mm 7개는 유지했다.
- 비아 위치·외경·네트·UUID, 배선86개, 부품32개, Ø3.0mm NPTH 고정홀4개, Ø11mm 기구 여유 영역은 유지했다.
- Ø0.20mm는 특별한 경우 사용할 수 있다. 대상 위치·사유·제작비 영향을 설명하고 사용자의 명시적 승인을 받은 해당 비아에만 예외로 적용한다. 승인 전에 임의로 사용하지 않는다. 현재 승인된 예외는0개다.
- 현재 최소 드릴·기본 넷클래스·라우터 프리셋·DRC·재생성 코드는 Ø0.25mm로 일치시켰다. 향후 승인된 예외는 적용 범위를 지정하여 DRC 규칙과 검증기에 등록하고 다시 검사한다.
- 최종 검사: DRC 오류0·경고0, 미연결0, 회로도 불일치0. 메모리에서 GND 푸어를 재계산한6층 모두 기존 저장 폴리곤과 차이0mm²여서 원본 푸어를 보존했다. 비아100개와 SMT패드74개는 같은 네트를 포함하여 동박·드릴 겹침0건이다.
