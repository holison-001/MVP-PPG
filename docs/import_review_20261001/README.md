- LVDS 송수신기를 XR33194ESBTR / XR33183ESBTR의 RS-422 구성으로 변경했습니다. 제조사 PDF와 U3/U6의 핀 기능·활성화 극성·설계 연결을 대조했습니다. 실제 PCB 랜드 0.80×0.63 mm, 열 중심 간격 2.40 mm, 피치 0.95 mm도 MaxLinear POD-00000179 Rev B와 일치합니다.

- Ø13.5 mm, 4층, 두께 0.8 mm입니다. 참조번호 37개는 구매 부품 28개와 구리 패드 9개로 구성되며, 앞면은 U1만 배치했습니다.
- 1층 배선을 줄여 일부를 2층으로 이동했고 3층은 3V3 전원 배선과 일부 신호를 사용합니다. PCB 중심은 40×40 mm 시트의 (20,17) mm입니다. 상세 층별 길이·푸어 면적은 [원본 층 변경 기록](../PCB_layers_20261001.md)에 있습니다.

## 제작 전에 남은 문제

**U4/U5의 MCP1703A /MC 실장 패턴은 여전히 다른 패키지용입니다.** 핀 1=VOUT, 4=GND, 8=VIN, 9=GND 연결은 맞지만 실제 패드 치수가 맞지 않습니다. 현재 이름은 `DFN-8-1EP_2x3mm_P0.5mm_EP0.61x2.2mm`이며 Linear/ADI DDB 패턴입니다.

| 항목 | 현재 보드 | Microchip MC 권장 PCB 랜드 |
|---|---:|---:|
| 마주 보는 패드 열 중심 간격 | 1.88 mm | 3.00 mm |
| 개별 랜드 | 0.87×0.25 mm | 최대 0.85×0.30 mm |
| 중앙 노출 패드 랜드 | 0.61×2.20 mm | 최대 1.75×1.55 mm |

기준은 [MCP1703A DS20005122C](https://github.com/holison-001/MVP-PPG/blob/2d90e067ea9b30de5ff0745b3141243147a49600/docs/datasheets/MCP1703A.pdf)의 인쇄 페이지 31 권장 랜드입니다. 위 표는 PCB 랜드이며 IC 금속 단자의 실제 치수와 구별해야 합니다. [보드에서 읽은 IC 패드 치수](board_ic_geometry.json)도 보존했습니다. 풋프린트·주변 배선을 교정하고 다시 검사해야 하며, 현재 DRC 통과는 제조사 패키지와의 일치를 보증하지 않습니다.

기존 `gerber/`, 루트 Gerber ZIP, 좌표 CSV, 보드 STEP는 이전 LVDS 이력입니다. 새 RS-422 제조 자료로 사용할 수 없습니다. 이번 가져오기에서는 거버·BOM을 생성하거나 갱신하지 않았습니다. 최상위 `PPG_PCB_v0.8_사양.md`도 LVDS 이력으로 표시했습니다. 현재 회로 설명은 [RS-422 변경 문서](../RS422_update_20261001.md)를 사용합니다.

D1 이후 U4 입력의 잔류 과도전압, VREF 및 U3/C6 디커플링 경로, 실제 케이블 통신·ESD·발열·광학 하우징 검증은 남아 있습니다. 이번 검토는 그러한 실측 결과를 제공하지 않습니다.
