# MVP-PPG PCB 반영 기록 — 2026-10-01

D1–D8·FB1을 현재 회로도에 맞춰 배치하고 배선을 완료했다. 탑면은 U1(MAXM86161) 하나이며 U1의 원점·0° 배치를 유지했다. 보드 외경은 13.5 mm, 4층이다. 기존 PCB 파일에 사양과 달리 1.6 mm로 저장된 두께를 원설계의 0.8 mm로 수정했다. 구체적인 제조사 유전체 적층은 별도로 확정하지 않았다.

## 전기적 변경

- `/12V_IN`: J1.1, D1.1, FB1.1. `12V`: FB1.2, C13.1, U4.8. 비드 앞뒤를 별도 넷으로 배선했다.
- D1.2 및 D2–D8.2는 GND. D2–D8.1은 각각 TXP, TXN, RXP, RXN, SWDIO, SWCLK, NRST이다.
- TVS 8개는 각각 폭 0.20 mm·길이 약 0.525–0.570 mm의 GND 연결과 별도 0.50/0.25 mm 관통 비아를 가진다.
- In1.Cu는 GND, In2.Cu는 3V3 평면이다. 모든 배선 세그먼트는 F.Cu/B.Cu에 있다. 자동 배선에서 In1.Cu에 들어간 5V_LED 두 구간(합계 약 3.543 mm)을 F.Cu로 옮겨 GND 평면의 연속성을 확보했다.
- 총 183개 배선 세그먼트·34개 비아. 최소 배선 폭은 0.10 mm이다. MCU UART_RX 탈출부에는 이 최소 폭을 사용했다.
- 부품 이동에 맞춰 배선을 다시 연결하고, C4의 VLDO 탈출 공간을 확보하도록 C1/C4/C5 GND 연결을 조정했다.

## 검증과 출력

KiCad 10.0.6으로 현재 회로도 XML을 새로 추출해 부품·111개 번호 패드·44개 넷·UUID 경로·필드를 비교했다. DRC 결과는 오류 0, 미연결 0, 회로도 불일치 0이다. 회로도 ERC도 위반 0이다. 드릴이 SMD 패드를 침범하는 경우와 같은 넷 비아끼리 겹치는 경우는 0이다.

남은 경고 6건은 기존 U4/U5 실크가 마스크에 잘리는 5건, U2의 기존 실크 제거로 인한 라이브러리 차이 1건이다. DRC 규칙을 완화하거나 경고를 숨기지 않았다. 실크 출력에는 솔더마스크 개구 차감을 적용했다.

- Gerber·Excellon 드릴·드릴 도면 18개를 ZIP으로 묶었고 ZIP 내용과 개별 파일 일치를 확인했다.
- 좌표 35개에서 top=U1, bottom=34개를 확인했다. 구리 패드 J1–J9도 좌표와 BOM에 포함된다.
- PCB PDF 7페이지, 회로도 PDF 1페이지, 앞뒤 SVG, 통합 BOM 16그룹·35레퍼런스를 갱신했다.
- BOM은 DNP 0이며 저항 `4.7k/1%`, 커패시터 F 생략, 패키지명과 데이터시트 파일명 표기를 유지했다. 알려진 R/C 보충 사양의 근거는 BOM 출처 JSON에 기록했다.
- 현재 STEP은 부품을 제외한 기판 모델이다. 공칭 기판 0.8 mm와 별개로 KiCad 기본 동박·마스크 표현을 포함한 STEP의 Z 범위는 약 0.81 mm이며 제조사 확정 적층을 의미하지 않는다. 과거 부품 포함 STEP·렌더·라우팅 세션은 `legacy_before_esd/`로 옮겼다.

검증 파일은 이 폴더의 [verification_v08](verification_v08/)에 있다. `netcheck_v08.py`는 부품·넷·면뿐 아니라 두께 0.8 mm·4층·원형 외경도 검사하므로 기존 두께 불일치의 재발을 탐지한다. 기본 `run_v08.sh`는 현재 배선 PCB를 보존하고 검증을 통과한 출력만 갱신한다.

## 실제 시험에서 확인할 항목

D1 `SPHV15-01ETG`의 명시 클램프 전압 22 V @ 1 A는 U4 `MCP1703A`의 입력 절대최대 18 V보다 높다. 회로도에 지정된 부품은 유지했다. FB1·C13 후단의 잔류 과도전압과 보드 ESD 내성은 실제 시험으로 확인해야 한다. 이번 검증은 회로도 일치·배치·배선 규칙 검사이며 ESD 시험이나 LVDS 신호 무결성 측정 결과를 의미하지 않는다. 선정 근거 링크는 [README](../README.md)에 있다.
