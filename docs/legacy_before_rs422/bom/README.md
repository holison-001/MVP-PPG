# MVP-PPG 회로도 BOM

현재 `kicad/ppg_pcb_v08.kicad_sch`를 KiCad로 읽어 생성한 부품별 통합 BOM입니다. 동일한 값·주문형번·제조사·패키지·데이터시트·보충 사양을 가진 부품은 레퍼런스를 모아 수량을 계산합니다. DNP 및 BOM 제외 속성이 있는 부품은 제외합니다.

현재 출력은 **16그룹·35개 레퍼런스**이며, 구매 부품 26개와 PCB 구리 패드 9개를 포함합니다. DNP 및 BOM 제외는 각각 0개입니다. J1–J6 케이블 납땜 패드와 J7–J9 SWD 테스트패드는 각각 묶고 신호 이름은 비고에 보존합니다.

- `MVP-PPG_BOM_부품별통합_DNP제외_값표준화_v2.xlsx`: 검토용 엑셀
- `ppg_pcb_v08_BOM.csv`: 엑셀과 동일한 9열·16그룹, UTF-8 BOM 인코딩
- `bom_sources.json`: 원래 값·풋프린트·출처 URL과 표시값, 제외 레퍼런스의 감사용 기록

## 표기와 사양 근거

저항의 Ω, 커패시터의 F, 인덕터의 H를 생략합니다. 저항 기본 5%는 생략하고 명시된 다른 허용오차는 `4.7k/1%`, `1k/0.1%`로 표기합니다. 커패시터 예시는 `10u/6.3V/X5R`입니다. 페라이트 비드는 저항과 구분하여 `600Ω@100MHz/0.9A`로 표시합니다.

2026-10-01 검토된 v2 BOM에 따라, 기존 v0.8 BOM에 명시된 R1/R2의 1%, C4/C5/C12/C14의 X5R, C6/C7/C11의 16V/X7R를 보존합니다. 생성기의 보충 사양은 기존 레퍼런스·원래 값·풋프린트가 모두 일치하고 MPN이 비어 있을 때만 적용합니다. 실제 주문형번이 지정된 부품에는 이 보충값을 덮어쓰지 않습니다.

수동소자의 기존 예시 MPN은 확정 주문형번으로 승격하지 않고 비고에만 기록합니다. C13의 예시 `GRM155R61E105KA12`는 회로도에 적힌 X7R과의 적합성을 확인해야 합니다.

데이터시트는 회로도 필드의 PDF 파일명만 표시합니다. U4/U5는 저장소에서 기존에 참조한 Microchip `20005122B.pdf`를 사용합니다. FB1은 제조사 제품 페이지로 연결되어 PDF 파일명을 비워 두며, 다른 미지정 자료도 추정해서 채우지 않습니다. PDF 원문 파일은 엑셀에 포함되지 않습니다.

BOM은 회로도의 부품·사양 목록입니다. PCB의 배치·배선 및 제조 검증 상태는 저장소의 최신 검증 결과를 따릅니다.

## 다시 생성

KiCad 10의 `kicad-cli`와 Python `openpyxl`이 필요합니다. 어느 작업 디렉터리에서도 다음과 같이 실행할 수 있습니다.

```sh
python /path/to/MVP-PPG/kicad/bom_v08.py
```

기본 결과는 저장소의 `bom/`에 저장합니다. `--schematic <회로도>`와 `--output-dir <폴더>`로 입력과 출력 위치를 지정할 수 있습니다. KiCad 실행 파일이 PATH에 없으면 `KICAD_CLI`에 지정합니다. 생성기는 현재 회로도에서 매번 XML 넷리스트를 다시 읽으며 기존 캐시·BOM·엑셀에 의존하지 않습니다. 회로도와 PCB는 수정하지 않고 Gerber ZIP이나 미리보기도 만들지 않습니다.
