## 남은 실물 검증과 출력 상태

ERC/DRC 통과는 실물 전원·통신·광학·ESD·발열 성능이나 조립 공정 적합성을 보증하지 않습니다. 독립 검사에서 다음 배선 특성을 별도 관찰 항목으로 기록했습니다.

- U3와 C6 전원 패드의 중심 간격이 2 mm를 넘습니다. 전원 배선과 접지 비아를 포함한 디커플링 경로는 실물 통신·전원 시험에서 확인해야 합니다.

기존 거버·좌표 CSV·BOM·보드 STEP·회로도 PDF·이전 배치/층 렌더는 이번 교정을 반영하지 않은 이력입니다. 이번에는 새 거버나 BOM을 생성하지 않았습니다. 전체 IC 3D 모델의 완비도 이번 검증 범위에 포함하지 않았습니다. 최신 전기/기구 검토에는 위 PCB·회로도와 이 폴더의 새 그림을 사용하세요.

`kicad/run_v08.sh --check-only`는 임시 사본에 로컬 풋프린트·3D·데이터시트 의존성을 복사하고 ERC, 핀/층 검사, MC 제조사 치수 검사와 DRC를 실행합니다. 저장 과정에서 프로젝트 규칙이 바뀌지 않도록 프로젝트 원본 바이트를 복원합니다. 자동 재생성 옵션은 새로운 배선 후보를 만들며 수동 검토한 PCB를 덮어쓰지 않습니다. [최종 자동 검사 실행 기록](wrapper_check.json)에서 원본 해시 보존과 검사 통과를 확인할 수 있습니다.
