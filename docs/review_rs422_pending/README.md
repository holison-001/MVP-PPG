# RS-422 배선 검토본 — NRST 1개 미연결

**이 폴더는 이전 검토 이력입니다.** 이후3층을 굵은 전원선과 신호 배선으로 변경해 미연결0건으로 마무리했습니다. 현재 상태는 [주 PCB](../../kicad/ppg_pcb_v08.kicad_pcb)와 [최신 층 변경 기록](../PCB_layers_20261001.md)을 확인하십시오. 아래 내용과 이미지들은 당시 스냅샷의 상태입니다.

`kicad/ppg_rs422_review.kicad_pcb`는 D2/D4를 삭제한 37레퍼런스 검토 스냅샷입니다. **아직 완료본이 아닙니다.** 주 PCB `ppg_pcb_v08.kicad_pcb`는 이전 LVDS 이력이며, 검증을 통과한 뒤 교체합니다. 회로도와 프로젝트 설정도 `ppg_rs422_review` 이름으로 함께 저장했습니다.

- TOP: PPG U1만 배치. BOTTOM: 나머지 36레퍼런스.
- F.Cu/B.Cu: 신호 배선. In1.Cu: GND. In2.Cu: 3V3.
- UART 송수신과 I2C 연결 완료. 남은 연결은 U2.4 NRST와 J9/D8 쪽입니다.
- 새로 실행한 DRC: 일반 설계규칙 오류 0, **미연결 1**, 회로도 불일치 0, 경고 7. 전체 검증은 미연결 때문에 실패 상태입니다.
- 경고 7건: 단일 층에만 연결된 비아 2, 외곽 실크 간격 4, U2 라이브러리 도형 불일치 1. 최종 정리 대상입니다.
- 독립 도형 검사: 부품 본체/조립 여유 겹침 0, 최소 구리–외곽 0.302168 mm, 이종 넷 구리 간격 0.150000 mm, 비아 드릴–SMD 구리 0.026574 mm. 비아는 양면 텐팅했습니다.
- U3/C6 전원 패드 간격이 2 mm를 넘는 점은 최종 전원 귀환 검토에 남겨 두었습니다.

## 남은 배선

현재 배치에서 J9 둘레 반경 0.55–0.90 mm의 비아 후보 2,540개를 검사했지만, 다른 넷 구리 간격 또는 드릴–패드 간격을 만족하는 후보가 없었습니다. 이는 검사한 영역의 결과이며 모든 배치에서의 불가능성을 뜻하지 않습니다. C5를 왼쪽으로 조금 옮기는 예비 후보 7개는 남아 있으며, NRST 배선까지 함께 검증한 완료안은 아닙니다.

[탐색 결과](RESULT.md), [J9 링 검사](j9-ring-results.json), [C5 예비 후보](left-feasible-poses.json), [DRC](drc.json), [독립 검사](independent_audit.json), [이미지 원본 해시](layers_png/source_manifest.json)를 함께 보관했습니다.

C5 예비 위치와 5V_LED 배선을 함께 조정한 추가 검사에서는 NRST 연결 자체는 가능했지만 5V_LED를 모두 복구하지 못했습니다. [추가 검사 기록](nrst_c5_power_repair_attempts.json)을 남겼으며, 이 불완전한 시도들은 검토용 PCB에 반영하지 않았습니다. 다음 단계는 외층 배선을 위한 배치 조정 범위를 넓히거나, GND 내층을 유지하면서 3V3 내층 일부를 신호 배선에 사용하는 안을 검토하는 것입니다.

거버·BOM은 사용자 승인 전까지 추가 생성하거나 갱신하지 않습니다. 이 폴더의 PCB·이미지·검증 결과는 검토용입니다.
