# MVP-PPG RS-422 회로도 BOM

현재 회로도 기준 **20그룹·39레퍼런스**이며, 구매 부품 30개와 구리 패드 9개를 포함합니다. DNP와 BOM 제외 항목은 제외하고 같은 부품은 레퍼런스를 모았습니다. 패키지명과 데이터시트 파일명 표기를 사용합니다.

저항은 Ω와 기본 5%를 생략하고, 다른 오차율은 `120/1%`처럼 표시합니다. 커패시터 F와 인덕터 H는 생략합니다. R4의 주문형번은 미확정이며, 값이 없는 기존 부품 사양을 추정하여 확정하지 않습니다.

- `MVP-PPG_BOM_부품별통합_DNP제외_값표준화_v2.xlsx`: 검토용 엑셀
- `ppg_pcb_v08_BOM.csv`: 동일한 표
- `bom_sources.json`: 원본 값·출처·그룹화 근거

기존 R1/R2의 1%, 커패시터 보충 사양은 이전 검토 규칙을 유지합니다. R3/R5–R8의 확정 MPN과 고유 사양에는 기존 보충값을 덮어쓰지 않습니다. 참고 PDF는 `../datasheet/pdf/`에 있습니다.

회로도 BOM이며 PCB 반영·제조 승인 상태를 보증하지 않습니다. [RS-422 변경 기록](../docs/RS422_update_20261001.md)을 확인하십시오. 다시 생성: `python kicad/bom_v08.py`(저장소 루트 기준).
