# RS-422 배치 탐색 — 검증 불합격

이 파일은 39개 부품 배치의 검토 기록이며 PCB 제조용 좌표가 아닙니다. 탑면 U1 고정, 나머지 38개 바텀, Ø13.5 mm 조건을 적용했습니다.

최종 후보: 코트야드 겹침 44쌍·0.513177 mm², 최소 구리–외곽 간격 0.262909 mm(요구 0.30 mm). 실제 본체 겹침과 패드 사이 0.15 mm 미만 간격은 없었지만 조립 여유·외곽 간격 기준을 통과하지 못했습니다. 배치 불가능의 증명은 아니며 추가 배치 최적화 또는 소형 보호소자 재선정이 남았습니다.

정확 판정: mechanical_candidate_assessment.json. 후보: packing_strict_best.json. 각 회전의 실제 도형: packing_geometry_physical.json. 원 보고서의 /workspace/ppg-rs422-work 경로는 탐색 당시 위치이며 같은 파일을 이 폴더에 보존했습니다. 후보는 회로도 모델을 PCB 배치로 승격하거나 Gerber로 출력하지 않았습니다.
