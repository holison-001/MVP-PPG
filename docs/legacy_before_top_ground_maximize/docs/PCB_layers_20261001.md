# 3층 전원 배선 및 1층 GND 변경

사용자 요청에 따라3층의 3V3 전체 푸어를 삭제하고, 전원 비아10개를 **0.40 mm 배선**으로 연결했습니다. 총 전원 배선 길이는27.079 mm이며,3V3 패드14개 모두 레귤레이터 U5.1까지 실제 구리 연결을 확인했습니다. 검증 규칙은3층 3V3의 최소 폭0.30 mm를 요구하며 이번 보드에서는 전 구간0.40 mm를 사용했습니다.

SWDIO와12V의1층 비아 사이 구간 일부를3층으로 옮겼습니다.3층에서12V는0.30 mm, NRST와 SWDIO는0.10 mm입니다.1층 남는 영역은 GND 푸어로 채우고 연결되지 않은 구리 섬은 제거하도록 설정했습니다.2층 GND면은 유지했습니다.3층에는 푸어를 두지 않습니다.

이전 NRST 미연결 검토본에 비해 부품 위치·회전·값·패드 연결은 그대로입니다. MCU 주변3V3 비아를(-0.05, -0.25), GND 비아를(0.15, 0.95) mm로 옮겨 NRST 탈출 공간을 확보했습니다. NRST는3층을 사용해 완결했고, 사용하지 않는 단일 층 비아2개와 UART_TX의 막다른 배선을 정리했습니다. TXP의 바텀 연결은 짧은 구리 배선으로 유지했습니다.
