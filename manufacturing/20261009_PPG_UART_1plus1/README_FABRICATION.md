# PPG 1 + UART 1 — 연배열용 거버·드릴 / 2026-10-09

사용자 지정: PPG 1개와 UART 연결 보드 1개를 한 세트로 제작. 원본 부품 배치·배선·전층 GND를 그대로 출력하고 배열 좌표로 평행 이동했다. 아래 두 닫힌 외곽은 각 보드의 **분리 후 완성 외곽**이다.

**제조사 CAM 연배열 작업용 데이터다. 지지 탭·가이드바·툴링이 확정된 자체 지지 SMT 패널은 아니다.** PPG 외곽에 GND와 부품이 가까우므로 외곽선 위 mouse-bite 타공을 임의 적용하지 않는다. 제조사가 외부 희생탭·최종 라우팅·조립 지그 방식을 검토하고, 동박 및 부품 간섭 없는 CAM 도면을 확정해야 한다. 가이드바 점선은 검토 도면에만 있고 거버 외형·드릴에는 없다.

## 데이터 구성

- `array_1plus1/`: 동일 원점의 1+1 거버 13개(동박 6, 마스크 2, 실크 2, 페이스트 2, 외형 1)와 PTH/NPTH 드릴 2개.
- 제조 ZIP에서는 페이스트 2개를 `stencil/`로 구분했다. PCB 제조 동박·마스크·실크·외형은 `gerber/`, 드릴은 `drill/`이다.
- `units/PPG/`, `units/UART/`: 개별 보드의 원점 정규화 출력. 제조사가 배열을 재구성할 때 사용하는 대안이며, 1+1 파일 위에 중복 합성하지 않는다.
- `ARRAY_LAYOUT.png`, `.svg`: 공통 좌표와 완성 외형 치수, CAM 가이드 여유 제안.
- `PPG_UART_부품좌표_20261009.xlsx`: 전체 풋프린트 좌표 및 실장 대상 구분. 실장 회전각·풋프린트 기준점은 업체 장비 기준과 대조한다.
- `review/copper_6layers.png`: 실제 최종 거버의 6층 동박 미리보기.
- `verification/`: 원본 검사, 출력 명령·파일 검사·좌표 검증. 자동 `.gbrjob`의 미확정 적층값은 제조 사양으로 사용하지 않는다.

## 좌표와 외형

모든 제조 파일은 mm, 1:1, 위에서 본 공통 좌표다. +X는 오른쪽, +Y는 위쪽이며, 바닥면도 미러하지 않는다. 두 보드 배열 회전은 0°다.

| 항목 | 개별 출력 기준 | 1+1 배열 위치 |
| --- | --- | --- |
| UART | 완성 외곽 좌하단 (0,0); 52 × 25 mm | 좌하단 (5,5), 우상단 (57,30) |
| PPG | 원형 중심 (0,0); Ø13.5 mm | 중심 (66.75,17.5) |
| 보드 간격 | 완성 외곽 사이 최소값 | 3.0 mm |
| 완성 보드 전체 경계 | 가이드바 제외 | 68.5 × 25 mm |
| 점선 가이드 여유 제안 | 거버에 없음 / CAM 확정 전 | 78.5 × 35 mm |

CAM에서 위치·원점·회전을 바꾸면 첨부 배열 실장 좌표를 그 변환에 맞춰 재생성해야 한다. KiCad 원본 좌표는 Y가 아래로 증가하지만 위 표·거버·엑셀 배열 좌표는 Y가 위로 증가한다. UART 원본 (88,123.5), PPG 원본 (20,17)을 각각 개별 출력 원점으로 사용했다.

## 층 순서와 드릴

| 순서 | 파일 접미부 | 내용 |
| --- | --- | --- |
| L1 | F_Cu | 탑 동박 |
| L2 | In1_Cu | GND 전용 |
| L3 | In2_Cu | 신호 + GND |
| L4 | In3_Cu | 전원·신호 + GND |
| L5 | In4_Cu | GND 중심 |
| L6 | B_Cu | 바닥 동박 |
| 양면 | F_Mask / B_Mask | 솔더마스크 개구 |
| 양면 | F_Silkscreen / B_Silkscreen | 실크; 마스크 개구 차감 |
| 양면 | F_Paste / B_Paste | 스텐실 개구 |
| 외형 | Edge_Cuts | 완성 보드 외곽 2개; 선 중심 기준 |

6층, 공칭 0.8 mm. PTH는 **Ø0.25 mm 164개**(PPG 64 + UART 100), NPTH는 **Ø3.0 mm 4개**(UART 고정홀)다. 드릴은 Excellon/mm/절대좌표/소수점 표기이며, 원본 개별 출력의 좌표 반올림 허용 범위는 축당 0.0005 mm다. 비아 랜드 Ø0.50 mm, 환형 링 0.125 mm, 승인된 Ø0.20 mm 비아 예외는 없다. 비아 텐팅은 원본 설정을 유지했다.

## CAM·제조 확인 사항

1. 두 원본의 6층 순서와 공칭 0.8 mm는 일치하지만, 동박·유전체 두께/재질·두께 공차·표면처리는 미확정이다. 동일한 제조 적층으로 확정할 것.
2. PPG 실제 외곽 GND 이격은 탑 약 0.20 mm, 다른 층 약 0.30 mm다. UART J1 상단, J2/J3 하단 납땜 패드 부근과 Ø11 mm 고정홀 조립 영역에는 지지 탭/조립 지그 간섭을 만들지 않는다. 현재 파일에는 V-cut·분리 타공이 없다.
3. 한샘디지텍 공개 기준은 라우터 외형–동박 이격 0.30 mm, 비아 환형 링은 1/2 oz 최소 0.10 mm·1 oz 최소 0.15 mm다. 현재 PPG 탑 외곽 0.20 mm 및 전체 비아 링 0.125 mm, 프로젝트 홀–동박 간격 0.20 mm의 적용 가능 여부를 선택한 적층으로 확인할 것. [제조사 작업사양](https://www.hsdgt.com/order/information.html)
4. 공개 양산 추가가격표에는 Ø0.20·0.25 mm 비아가 함께 기재되어 있으므로 Ø0.25 mm 변경만으로 추가비 면제를 단정하지 않는다. 실제 주문 유형과 견적에서 확인할 것. [제조사 양산가격](https://extern.hsdgt.com/order/mass.html)

이 확인 사항은 원본 보드 변경이나 제조 발주를 승인한 기록이 아니다. 이번 작업은 사용자가 요청한 제조 데이터와 좌표 출력이다.
