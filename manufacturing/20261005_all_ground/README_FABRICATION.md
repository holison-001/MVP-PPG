X2 속성이 포함된 mm 거버입니다. 모든 파일은 위에서 본 동일 좌표이며 바텀도 미러하지 않았습니다. 공통 원점은 보드 중심이며 PCB 보조 원점 (20,17)mm를 사용했습니다. Mask 거버는 개구를 표시하며 X2 FilePolarity=Negative를 유지합니다. 비아는 원본 설정대로 앞뒤 tenting입니다. 실크는 솔더마스크 개구를 차감했습니다.

PTH 드릴은 Excellon/mm/절대좌표/소수점 표기이며 Ø0.20mm 56개, Ø0.25mm 15개, 총71개입니다. 비도금 홀은 0개이며 NPTH 파일은 이를 표시하는 빈 파일입니다. 홀 좌표는 KiCad Excellon 출력 해상도 0.001mm에 따라 반올림되었습니다. 원본 대비 각 축 오차 0.0005mm 이하를 검증했습니다. 비아 랜드 외경은 모두 Ø0.50mm입니다.

6층 모두 연결된 GND 푸어를 포함합니다. L1~L5 외곽 연속 띠를 유지하며 L6는 부품·배선 사이 가용 영역을 채웠습니다. 모든 GND 영역의 J2.1 연결, 고립 동박0, 프로젝트 DRC 오류0, 미연결0, 회로도 불일치0을 확인했습니다. 기존 경고5건은 U4/U5 바텀 실크 외곽 근접4건과 U2 라이브러리 도형 차이1건입니다. 실크 경고 위치는 변경하지 않았습니다.
