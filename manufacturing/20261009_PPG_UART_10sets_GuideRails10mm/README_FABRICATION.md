# PPG 10 + UART 10 — 10세트, 10 mm 가이드바 패널

2026-10-09 사용자 지정 사진의 상·하 가이드바, 가이드 홀, 피듀셜 형식을 적용했다. 구성은 PPG 10개 + UART 10개, 2열 × 5행이다. **생산용 거버에 실제 가이드바·라우팅 슬롯·연결 탭이 들어 있다.** 앞서 만든 1+1 CAM 배열용 ZIP 대신 이 패키지를 사용한다.

## 패널 규격

| 항목 | 적용값 |
| --- | --- |
| 외곽 | 157 × 177 mm |
| 구성 | 10세트 / PPG 10개 + UART 10개 |
| 층·공칭 두께 | 6층 / 0.8 mm |
| 상·하 가이드바 | 각각 10 mm |
| 좌우 캐리어 최소 폭 | 3 mm |
| 가이드 홀 | GH1~GH4, Ø3 mm NPTH |
| 피듀셜 | TOP 3개 + BOTTOM 3개; 동박 Ø1 / 마스크 Ø3 mm |
| 라우팅 공구 | Ø2 mm; 슬롯 끝단 R1 |
| 연결 탭 | 보드당 UART 6개·PPG 3개, 총 90개; 최소 목폭 3 mm |
| PTH | Ø0.25 mm 1,640개 |
| NPTH | Ø3 mm 44개 = UART 고정홀 40 + 가이드 홀 4 |

피듀셜에는 페이스트와 드릴이 없으며, 세 모서리에 비대칭 배치했다. 프레임에는 피듀셜 외 기능 동박을 추가하지 않았다. 업체 CAM 동박 균형 보정은 피듀셜·홀·라우팅 여유와 단품 회로 절연을 유지하는 조건으로 검토한다.

## 좌표·세트 순서

단위 mm, 물리적 패널 좌하단 (0,0), +X 오른쪽·+Y 위쪽의 공통 TOP VIEW다. 바닥면 파일도 미러하지 않는다. 세트는 위쪽 왼쪽부터 S01/S02, 다음 행 S03/S04, 마지막 행 S09/S10이다. 모든 단품 회전은 0°다.

| 기능 | X | Y |
| --- | ---: | ---: |
| GH1 | 3.5 | 5 |
| GH2 | 153.5 | 5 |
| GH3 | 3.5 | 172 |
| GH4 | 153.5 | 172 |
| FID_T1 / FID_B1 | 10 | 5 |
| FID_T2 / FID_B2 | 147 | 5 |
| FID_T3 / FID_B3 | 10 | 172 |

S09의 UART 좌하단은 (5,12), PPG 중심은 (66.75,24.5)다. 오른쪽 열은 X +78.5 mm, 위쪽 행은 Y +32 mm로 반복한다. UART 단품은 52×25 mm, PPG는 Ø13.5 mm이며 같은 세트 사이 완성 외곽 간격은 3 mm다. 전체 20개 변환은 `panel_manifest.json`에 기록했다.

## 분리 방식 — 반드시 유지

**조립 후 지그로 보드를 지지하고 CNC 라우터로 solid tab을 절단한다. 수동 꺾기·V-cut·mouse-bite 방식이 아니다.** PPG의 외곽 GND와 부품 여유를 유지하기 위한 선택이다. GND를 피하기 위해 탭에 분리 타공을 넣지 않았다.

- 생산 `Edge_Cuts.gbr`에는 패널 바깥 외곽과 라우팅 제거 영역 80개가 있다. 탭 90개는 남아 있어 패널이 한 장으로 연결된다.
- `reference/FINISHED_UNITS_REFERENCE_ONLY.gbr`는 분리 후 20개 완성 보드 외곽이다. **생산용 외형과 합쳐서 선가공하지 않는다.** 합치면 탭이 잘려 패널을 유지할 수 없다.
- `reference/FINAL_TAB_CUT_TOOLCENTER_REFERENCE.dxf`는 Ø2 공구 중심의 최종 탭 절단 경로 참고다. 실제 가공 코드가 아니며 고정 지그·절단 순서·진입/퇴출·공구 길이·Z깊이·이송은 조립업체가 장비에 맞게 설정한다. PPG 0° 탭의 원호 경계 때문에 90개 탭이 100개 경로 조각으로 표현된다.
- `reference/panel_geometry.geojson`에는 제작 라우팅 및 최종 탭 절단 공구 중심선과 완성 외곽이 구분되어 있다.

## 파일 구분

- `gerber/`: 동박 6층, 양면 마스크·실크, 실제 생산 외형.
- `drill/`: PTH / NPTH 각각 1개.
- `stencil/`: 양면 페이스트. 피듀셜·납땜 패드·고정홀은 원본/캐리어 설정에 따라 제외되어 있다.
- `assembly/PPG_UART_10세트_부품좌표_20261009.xlsx`: 단품 원본과 배열 좌표 740개, 별도 패널 가이드·기준점 10개. 실장 부품 560개, 납땜 패드 140개, 단품 고정홀 40개를 구분했다. 제조사 좌표계로 변환할 때 면·회전각·풋프린트 기준점을 대조한다.
- `PANEL_LAYOUT.png` 및 `review/`: 치수 도면과 실제 거버 검토 이미지. 프리뷰의 동박 색은 레이어 구분용이다.
- `verification/`: 제조 파일·기구·좌표의 독립 검사 결과.

층 순서: **F.Cu → In1.Cu → In2.Cu → In3.Cu → In4.Cu → B.Cu**. 거버 X2, mm, 1:1. Excellon은 mm·소수점·절대 좌표다. `Edge.Cuts`의 선 중심이 가공 경계다. 작은 선분 근사는 공구 곡선을 0.0001 mm 이내로 표현한다.

## 확인 결과와 남은 제조 조건

20개 보드와 가이드바가 한 기판으로 연결되고, 제작 라우팅 및 최종 탭 절단 경로의 완성 보드·부품·패드·드릴 침범이 없음을 기하 검사했다. 모든 탭의 최소 목폭은 3 mm다. 원본 거버를 평행 이동한 단품 동박·마스크·실크·페이스트와 캐리어의 추가 형상을 최종 출력과 비교했고, 드릴 좌표·크기·피듀셜·층 순서도 검사했다. 좌표 Excel은 최종 패널 변환과 대조했다. 이 검사는 실물 패널의 강성·리플로 변형·지그 성능 시험을 대신하지 않는다.

원본 PPG·UART 회로/배치/배선은 바꾸지 않았다. PPG 원본의 기존 일반 경고 5건과 회로도 속성 경고 9건, UART 원본 경고 0건은 이전 검증 기록과 같다. 두 원본 모두 DRC 오류·미연결 0건이다.

공칭 0.8 mm의 실제 6층 동박·유전체 구성, 표면처리와 공차는 제조사와 확정해야 한다. 기존 비아 환형 링 0.125 mm, PPG 탑 GND 외곽 이격 약 0.20 mm, 홀–동박 규칙 0.20 mm의 업체 수용 조건도 그대로 남아 있다. 임의로 0.20 mm 비아 예외를 추가하지 않았다.
